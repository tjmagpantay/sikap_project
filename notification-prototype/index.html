🔔 Notification Prototype Testing

Quick Test Workflow

Step 1: Login as Employer → Go to Jobs → Post a job → Admin + Jobseeker get notifications
Step 2: Login as Jobseeker → View dashboard → Check notifications (🔔 icon) → Apply to jobs
Step 3: Login as Employer → Go to Applications → Update application status → Jobseeker gets notified
Step 4: Login as Jobseeker → Check notifications → Click notifications to mark as read

👥 Switch Between Users

🔴 Alice Admin (ID: 1)

Manages system and receives notifications about all job postings

Login as Admin Admin → Jobs Admin → Applications

🟢 Bob Employer (ID: 2)

Posts jobs and manages applications from jobseekers

Login as Employer Employer → Post Job Employer → Applications

🟡 Charlie Jobseeker (ID: 3)

Views available jobs, applies, and receives application status updates

Login as Jobseeker Jobseeker → View Jobs
